
# Bienvenido a la Documentación del Proyecto

Este proyecto forma parte de la materia **Taller de Programación**.

## Objetivo

Documentar de manera clara la instalación, arquitectura,
funcionamiento y pruebas del proyecto de software.

## Características principales

- Arquitectura modular y escalable.
- Interfaz de usuario intuitiva.
- Documentación interactiva generada con MkDocs.
- Organización de contenidos mediante Markdown.

## Contenido de la documentación

En este sitio encontrarás los requisitos de instalación,
la arquitectura del sistema, la guía de uso,
los diagramas de clases, las pruebas y las conclusiones.
