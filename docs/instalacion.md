
# Instalación y Requisitos

## Requisitos previos

- Python 3.8 o superior.
- pip.
- Visual Studio Code.
- MkDocs.
- Material for MkDocs.

## Instalación

Crear un entorno virtual:

```bash
python -m venv venv
```

Activarlo en Windows:

```powershell
venv\Scripts\activate
```

Instalar las dependencias:

```bash
pip install mkdocs mkdocs-material
```

## Verificación

```bash
mkdocs --version
```
