
# Pruebas Unitarias

## Objetivo

Comprobar que las funciones del sistema
se comporten según lo esperado.

## Casos de prueba

| Caso | Resultado esperado |
|---|---|
| Entrada válida | Operación correcta |
| Entrada inválida | Mensaje de error |
| Datos incompletos | Validación de campos |

## Resultados

Registrar los resultados reales obtenidos
al ejecutar las pruebas.
