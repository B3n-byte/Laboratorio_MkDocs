
# Arquitectura del Sistema

## Descripción general

La arquitectura describe cómo se organizan
los componentes del proyecto de software.

## Componentes

- Presentación: interacción con el usuario.
- Lógica: procesamiento de las operaciones.
- Datos: almacenamiento y recuperación de información.

## Organización

Los componentes se documentarán de acuerdo
con la estructura real del proyecto.
